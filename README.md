# Escape From Ilnur — «Гараж у Ильнура»

Хоррор от первого лица: ты — Регина, потерялась в кукурузном лабиринте. Найди ключи, заведи ржавый Датсун в гараже и сбеги от Ильнура.

## Как играть

**Windows (проще всего):** скачай `Garage-u-Ilnura-*.exe` из раздела **Releases** и запусти двойным щелчком. Ничего устанавливать не нужно.

**В браузере (Chrome / Edge):**
1. Скачай репозиторий (Code → Download ZIP) и распакуй.
2. Запусти `start.bat` (нужен Python) или любой статический сервер в этой папке, например `python -m http.server 8765`.
3. Открой `http://localhost:8765`.

Игра не запустится двойным щелчком по `index.html` — файлы моделей и звука грузятся только по http.

Играй в наушниках и в темноте.

## Управление
`W A S D` — идти · `Shift` — бежать · `Ctrl` — красться · `Пробел` — прыжок · `E` — действие / спрятаться · `F` — фонарик · `N` — ночная камера · `M` — карта · `G` — бросить банку · `Esc` — пауза и настройки

## Что внутри
- 4 сложности, включая «Кошмар» с помощником Ильнура
- 4 места для поиска ключей, 4 вида укрытий, ловушки и отвлечение
- настройки чувствительности мыши, яркости, поля зрения и качества
- две случайные концовки, 7 пасхалок

Три.js r128, Web Audio. Сборка для Windows: папка `desktop` (`npm ci && npm run dist`).
