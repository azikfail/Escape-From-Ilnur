# Сборка «Гараж у Ильнура» для Windows

Готовый переносной файл с портретной иконкой: `../release/Garage-u-Ilnura-1.3.0.exe`.
Его можно передавать отдельно. Python, Node.js и подключение к интернету для игры не требуются.

Windows x64. Запуск двойным щелчком. F11 — полный экран, Alt+F4 — выход.
Остальное управление показано в меню игры. Настройки хранятся в профиле пользователя Windows.

Повторная сборка после изменения игры:

```powershell
cd D:\Dev\Garage\desktop
npm.cmd ci
npm.cmd run dist
```

`prepare.cjs` копирует исходный `index.html` и `assets`, заменяет ссылки CDN локальными файлами Three.js 0.128.0. Исходники игры не изменяются.
Electron использует внутренний протокол garage:// для загрузки файлов, моделей и звука, без локального сервера и без Python. Внешние сетевые запросы запрещены оболочкой.

Приложение не имеет цифровой подписи. Иконка из предоставленного портрета: `build/icon.ico` (16, 24, 32, 48, 64, 128 и 256 пикселей).
Файл `package-lock.json` фиксирует версии инструментов сборки.
